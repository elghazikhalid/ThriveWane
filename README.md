# ThriveWane

Handles cryptocurrency wallet import and export with advanced encryption and QR code generation for secure offline transactions.

ThriveWane is aimed at developers who need a straightforward, dependable solution.

## Technology Stack

- python

- unittest/pytest

## Installation

1. Clone the repository: `git clone https://github.com/minhokingkim/ThriveWane.git`
2. Install required dependencies: `pip install -r requirements.txt`

## Configuration

Most behavior is controlled via command-line flags:
- `--verbose`: enable detailed logging
- `--config <path>`: point to a custom config file
- `--dry-run`: preview changes without applying them
